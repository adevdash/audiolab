# Audiolab
## About Audiolab
Audiolab is a Python-based desktop application to play around with and analyze audio.

I was inspired to build Audiolab due to the infuriating interface of the Yamaha DX-7 and the amazing audio interface of Helm. I wanted to have an application that would combine Helm's great interface with expanded synthesis options such as FM. I also wanted to include analysis visualizations so that users could see how different modulation types and waveforms look in the frequency and time-frequency domains. Finally, I wanted to learn how to build GUIs in Python and brush up on my software development skills.

Audiolab is completely free and free and will never have ads or collect or sell your data.
